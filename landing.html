What it does

A small toolbar utility for capturing exactly what's playing in one tab — nothing else.

01

Writes as it records

Every second of audio is flushed to your disk immediately — not held in memory until you press stop.

02

MP4 or WAV, natively

Small AAC files for everyday use, or uncompressed WAV for editing — no plugins, no conversion step.

03

Your folder, your rules

The native save dialog lets you pick any location on disk — not locked to a Downloads subfolder.

04

Nothing leaves your machine

No server, no account, no analytics. The extension has nowhere to send your audio even if it wanted to.

How it works

Four steps, no settings screen to configure first.

Open the tab you want to capture

A video, a stream, a browser-based call — anything currently playing sound.

Click the toolbar icon

A small floating window opens and connects to that tab's audio automatically.

Pick a format and a save location

Choose MP4 or WAV, then the native "Save As" dialog — this is the only choice you make.

Record, then stop

The file keeps growing on disk automatically. Click stop, and you're left with a single finished file.

Most tab recorders hold your audio in memory

Which means a crashed tab, a browser update, or an accidental close can cost you the entire recording. This one doesn't.

Tab Audio Recorder

Questions

Does it record my microphone?

No — only the audio already playing inside the browser tab, never your microphone or voice.

Can I get MP3 directly?

Not yet — no browser can natively encode MP3 without a large external library. Convert the saved file in one command with free tools like ffmpeg if you need to.

Is my recording sent anywhere?

Never. There's no server behind this extension — audio is written straight to the folder you choose, on your own device.

Does it work in Brave or Firefox?

Brave, yes — after enabling brave://flags/#file-system-access-api manually. Firefox isn't supported yet: it lacks both the File System Access API and a tab-audio-capture equivalent.
